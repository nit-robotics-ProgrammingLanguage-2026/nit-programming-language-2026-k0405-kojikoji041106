# 課題0405 ロボット制御プログラム
車輪型ロボットを考える．車輪の半径をr/2[m]とする．このロボットを距離x[m]だけ走らせたい時，どれだけモーターを回転させればよいか，回転角度a[度]を求めるプログラムを作成せよ．

ただし，r=4かつ円周率=3.141592とする。

また，xの値はキーボードからdoubleとして入力するものとする．これらの値すべてをdouble型として計算した計算結果のa(桁数指定なし)を表示するようなプログラムとせよ．

ヒント: 360度回転すると，ちょうど円周の長さだけ進むことになる．つまり半径が2なので4π[m]進む．
すると180度で2π[m]，同様に考えていくと1度でπ/90[m]だけ進む．そうすると逆に1[m]だけ進むためには何度回転すればいいか。それが分かればx[m]だけ進むためには何度回転すればよいのか計算できる。
